## bosk-spring-boot

This is the subproject for the published `bosk-spring-boot` library for
Spring Boot support.

The maintenance endpoints also serve a generated OpenAPI document at
`<bosk.web.maintenance.path>/openapi.json`.
See [OPENAPI.md](OPENAPI.md) for the type mapping and usage notes.

See the [javadocs](https://javadoc.io/doc/works.bosk/bosk-spring-boot/latest/works.bosk.spring.boot/module-summary.html) for more information.
